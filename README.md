# NXT AI

NXT AI is the AI workspace for the NXT ecosystem.

## Current foundation

- NXT CLOUD / NXT PAD visual language
- Responsive ChatGPT/Claude-style conversation workspace
- NXT model selector
- Streaming-response UI state
- File attachment interface
- Tools menu
- NXT ecosystem project navigation
- Mobile responsive sidebar
- Frontend foundation ready for backend/model integrations

## Run locally

```bash
npm install
npm run dev
```

## Next integrations

The frontend is intentionally provider-agnostic. The next layer should add the secure server-side AI gateway, authentication, persistent conversations, file processing, web search, model routing, memory, tool/agent execution, image generation, voice, and NXT blockchain integrations.
